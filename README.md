# Template Konten Pemula

Template dan checklist konten untuk kreator pemula, dari Muse Konten.

## Bio

Aku Muko. Belajar bikin konten kreatif, simpel dan seru, setiap hari.

## Template Caption

Halo! Aku [nama]. Di sini kita belajar [topik], simpel dan seru, setiap hari. Ikuti aku, yuk! #[tagar1] #[tagar2]

Contoh:

Halo! Aku Muko, teman barumu di Muse Konten. Di sini kita belajar bikin konten kreatif, simpel dan seru, setiap hari. Ikuti aku, yuk! #MuseKonten #Muko

## Checklist Harian 1 Video

- [ ] Tentukan 1 ide video hari ini
- [ ] Buat video pendek (animasi atau narasi)
- [ ] Tulis caption dan periksa teksnya
- [ ] Posting ke semua platform
- [ ] Cek komentar dan balas dengan sopan
